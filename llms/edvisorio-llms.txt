# Edvisor.io

> Edvisor.io is a B2B international-education recruitment platform connecting education agencies with 700+ partner schools across 80+ countries. Agencies browse programs with live pricing, build quotes, manage the student journey through enrollment, and track commissions; schools distribute programs to 5,000+ agencies and manage their enrollment pipeline. The platform exposes a GraphQL API and webhooks for two-way synchronization with external CRM / back-office systems.

## API

- [GraphQL endpoint](https://api-v2.edvisor.io/graphql): Single GraphQL API — 226 queries, 203 mutations. Bearer API-key auth (Authorization header). Server-side only.
- [Developer docs](https://docs.edvisor.io/): Agency API guide, School API guide, Webhooks, Web 2 Leads form integration, GraphQL Playground.

## Specs

- [GraphQL SDL](graphql/edvisorio-api-v2-graphql.graphql): Schema derived from live introspection.
- [GraphQL introspection](graphql/edvisorio-api-v2-introspection.json): Raw introspection JSON.
- [Webhook catalog](asyncapi/edvisorio-webhooks.yml): student/school/campus/offering/startDateTemplate/studentQuote create/update/delete events.

## Artifacts
